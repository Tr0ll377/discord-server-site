# 📋 Guide d'installation complet\n\n## Étape 1 : Préparer votre environnement\n\n### Prérequis\n- Node.js (v18+) : https://nodejs.org\n- MongoDB (local ou Atlas) : https://www.mongodb.com\n- Un serveur Discord\n- Git\n\n### Cloner le projet\n\n```bash\ngit clone https://github.com/Tr0ll377/discord-server-site.git\ncd discord-server-site\n```\n\n## Étape 2 : Configurer Discord OAuth\n\n1. Aller sur https://discord.com/developers/applications\n2. Cliquer sur \"New Application\"\n3. Donner un nom (ex: \"Mon Serveur Site\")\n4. Aller dans l'onglet \"OAuth2\" > \"General\"\n5. Copier le **Client ID** et le **Client Secret**\n6. Dans \"Redirects\", ajouter :\n   ```\n   http://localhost:5000/auth/discord/callback\n   ```\n7. Sauvegarder les changements\n\n## Étape 3 : Configurer MongoDB\n\n### Option A : MongoDB local (recommandé pour le développement)\n\n1. Installer MongoDB : https://docs.mongodb.com/manual/installation/\n2. Lancer le service MongoDB\n3. La connexion sera : `mongodb://127.0.0.1:27017/discord-server-site`\n\n### Option B : MongoDB Atlas (cloud gratuit)\n\n1. Créer un compte sur https://www.mongodb.com/cloud/atlas\n2. Créer un cluster gratuit\n3. Créer un utilisateur (username + password)\n4. Récupérer la chaîne de connexion\n5. Format : `mongodb+srv://username:password@cluster.mongodb.net/discord-server-site?retryWrites=true&w=majority`\n\n## Étape 4 : Configurer les variables d'environnement\n\n1. À la racine du projet, créer un fichier `.env`\n2. Copier le contenu ci-dessous et remplir les valeurs :\n\n```env\n# Serveur backend\nPORT=5000\nCLIENT_URL=http://localhost:5173\n\n# Session\nSESSION_SECRET=generez_une_cle_aleatoire_longue_ici_12345abcdef\n\n# Base de données MongoDB\nMONGODB_URI=mongodb://127.0.0.1:27017/discord-server-site\n\n# Discord OAuth\nDISCORD_CLIENT_ID=votre_client_id_ici\nDISCORD_CLIENT_SECRET=votre_client_secret_ici\nDISCORD_CALLBACK_URL=http://localhost:5000/auth/discord/callback\n```\n\n### Générer une clé SESSION_SECRET sécurisée\n\nDans le terminal :\n```bash\nnode -e \"console.log(require('crypto').randomBytes(32).toString('hex'))\"\n```\n\nCopier le résultat dans `SESSION_SECRET`.\n\n## Étape 5 : Installer les dépendances\n\n```bash\nnpm install\n```\n\nCela installe les packages pour le backend ET le frontend (monorepo).\n\n## Étape 6 : Lancer le projet\n\n```bash\nnpm run dev\n```\n\nCe qui va :\n- Démarrer le backend sur http://localhost:5000\n- Démarrer le frontend sur http://localhost:5173\n\n## Étape 7 : Tester l'application\n\n1. Ouvrir http://localhost:5173 dans le navigateur\n2. Cliquer sur \"Se connecter avec Discord\"\n3. Autoriser l'accès\n4. Vous devriez être redirigé et voir votre profil\n5. Essayer de soumettre une suggestion\n6. Voter sur une suggestion\n\n## Configuration personnalisée\n\n### Changer le nom du serveur\n\nDans `client/src/App.jsx`, ligne 80 :\n```jsx\n<span>ServerName</span>  // Changer en votre nom\n```\n\n### Modifier les liens réseaux\n\nDans `client/src/App.jsx`, ligne 353-357 :\n```jsx\n<a href=\"https://youtube.com\" target=\"_blank\">YouTube</a>\n<a href=\"https://instagram.com\" target=\"_blank\">Instagram</a>\n// Ajouter/modifier vos URLs\n```\n\n### Changer les couleurs\n\nDans `client/src/App.jsx`, lignes 1-20 (variables CSS) :\n```css\n--accent: #8b5cf6;      /* violet */\n--accent-2: #22c55e;    /* vert */\n--bg: #0b1020;          /* fond noir */\n```\n\n### Ajouter des FAQ\n\nDans `server/src/index.js`, fonction `seedDatabase()` :\n```javascript\nawait Faq.insertMany([\n  {\n    question: 'Ma question ?',\n    answer: 'Ma réponse...'\n  }\n]);\n```\n\n### Ajouter des annonces\n\nDans `server/src/index.js`, fonction `seedDatabase()` :\n```javascript\nawait News.insertMany([\n  {\n    title: 'Titre',\n    content: 'Contenu...',\n    author: 'Auteur'\n  }\n]);\n```\n\n## Déploiement en production\n\n### Backend (Railway / Render / VPS)\n\n1. Créer un compte sur https://railway.app ou https://render.com\n2. Connecter le repository GitHub\n3. Ajouter les variables d'environnement (`.env`)\n4. Déployer\n\n### Frontend (Vercel / Netlify)\n\n1. Créer un compte sur https://vercel.com\n2. Connecter le repository\n3. Définir le dossier racine : `client`\n4. Déployer\n\n### Variables de production\n\n```env\nCLIENT_URL=https://votre-domain.com\nDISCORD_CALLBACK_URL=https://api-votre-domain.com/auth/discord/callback\n```\n\n## Dépannage\n\n### \"Cannot find module 'express'\"\n```bash\nrm -rf node_modules package-lock.json\nnpm install\n```\n\n### \"MongoServerError: connect ECONNREFUSED\"\n- Vérifier que MongoDB est lancé\n- Vérifier la `MONGODB_URI`\n\n### \"401 Unauthorized\" en votant\n- Vérifier que vous êtes connecté avec Discord\n- Vérifier que les cookies sont activés\n\n### \"Discord login n'affiche rien\"\n- Vérifier `DISCORD_CLIENT_ID` et `DISCORD_CLIENT_SECRET`\n- Vérifier que `DISCORD_CALLBACK_URL` est ajouté dans Discord Dev Portal\n\n## Support\n\nSi vous avez besoin d'aide :\n1. Vérifier les logs du terminal\n2. Vérifier que toutes les variables `.env` sont remplies\n3. Redémarrer le projet avec `npm run dev`\n"
